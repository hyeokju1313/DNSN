## 1. 배경

### 1.1 학사규정 안내가 어려운 이유

- 한국공학대 규정관리시스템에 공개된 규정은 353개다(폐지 55개 포함, 2026-09-27 수집 기준). 그중 학사와 직접 관련된 규정이 64개다(학칙 편 9개, 학사행정 43개, 학생행정 12개).
- 개정이 잦다. 학칙은 47차례 개정됐고 가장 최근 개정일은 2026-09-01이다.
- 하나의 질문에 답하려면 여러 규정을 이어 봐야 하는 경우가 많고, 학번에 따라 답이 달라지기도 한다. 예를 들어 "학사경고를 받으면 다음 학기에 몇 학점까지 들을 수 있나"에 답하려면 다음 세 조문을 차례로 봐야 한다.
  - 학칙 제33조: 평점평균 1.5 미만이면 학사경고
  - 학사경고자 관리 및 지원에 관한 규정 제6조: 지원 프로그램에 참여하지 않으면 수강학점 제한. 1개 이상 이수했거나 6학기 이상 이수자면 제한 없음
  - 학칙시행세칙 제22조의1: 2024학번까지 18학점, 2025학번부터 16학점

### 1.2 기존 학교 챗봇

- 학교는 2026-04-24에 AI 챗봇 '티노랑'을 열었다. 홈페이지 코드와 플러그인 설정을 보면 마인드로직의 Informe(여러 LLM과 RAG를 쓰는 상용 서비스) 기반이고, 학부용과 대학원용 챗봇이 따로 있다. 소개 문구에 따르면 홈페이지, 학사규정, 공지사항을 근거로 답한다.
- 이 프로젝트의 목표는 티노랑을 이기는 것이 아니다. 같은 시험 질문 일부를 티노랑에도 물어 참고 비교로만 쓴다(6.1절).

### 1.3 수컷 초파리 CNS 커넥톰

- Janelia, Google, 케임브리지 공동팀이 2026-09-03 Cell에 발표했다. 뇌와 신경삭(VNC)이 목으로 이어진 상태로 재구성한 첫 전체 중추신경계 연결도다. CC-BY 4.0으로 공개돼 있다.
- 커넥톰은 어떤 뉴런이 어떤 뉴런과 몇 개의 시냅스로 연결되는지를 적은 배선도다. 언어 지식은 들어 있지 않다. 그래서 이 프로젝트에서 커넥톰은 문장을 읽는 역할이 아니라, 읽은 내용을 조합해 답을 고르는 계산 구조를 맡는다.

## 2. 문제 정의와 가설

**문제 문장**: 조건, 예외, 여러 규정 연결이 포함된 학생의 학사규정 질문에 근거 조문과 함께 답하는 모델을, 수컷 초파리 전체 CNS 배선을 핵심 계산 구조로 삼아 만든다. 그리고 그 배선이 정확도에 실제로 기여하는지 검증한다.

| 가설 | 내용 | 검증 |
|---|---|---|
| H1 | 커넥톰 모델은 같은 인코더와 같은 학습 파라미터 수를 가진 GRU와 비슷하거나 더 나은 정확도를 낸다 | 6.1 비교 모델 |
| H2 | 그 성능은 초파리 배선 자체에서 나온다. 연결 수를 유지한 채 배선만 섞으면 성능이 떨어진다 | 6.2 대조군 |
| H3 | 어려운 질문(L3~L5)일수록 특정 뇌 부위(버섯체, 중심복합체 등)의 기여가 커진다 | 6.3 절제 실험 |
| H4 | 학습 질문이 적을수록 커넥톰 모델이 덜 과적합한다 | 6.4 데이터 양 실험 |

가설이 기각돼도 결과로 인정된다. 수업의 성공 기준이 "왜 실패했고, 무엇을 바꾸었고, 결과가 어떻게 달라졌는지"를 설명하는 것이기 때문이다.

## 3. 범위

- **포함**: 학부 학사규정(학칙, 학칙시행세칙, 학사행정 대학 편, 학생행정). 대학원 규정은 여유가 있으면 추가한다.
- **제외**: 자유 대화와 문장 생성, 로그인(SSO)이 필요한 '지침' 메뉴, 학사일정과 공지사항. 범위 밖 질문에는 "학사규정에서 확인할 수 없습니다"라고 답한다.
- **답변 방식**: LLM으로 문장을 생성하지 않는다. 조문에서 뽑은 답, 미리 만든 템플릿, 근거 조문 인용으로만 답한다. 지어낸 내용이 섞이면 커넥톰의 기여를 잴 수 없고, 규정 안내로서도 위험하기 때문이다.

2. 표는 markdown 표로 보존한다. 단순 텍스트로 뽑으면 학번과 학점의 짝이 끊기는 것을 확인했다. 학칙시행세칙 제22조의1을 그대로 뽑은 결과는 다음과 같다.
   ```
   졸업학점 135학점이상 (~2024학번)
   졸업학점 130학점 이하 (2025학번~)
   학사경고자 학기당 수강학점
   18학점
   16학점
   ```
3. 다른 규정을 가리키는 링크(예: "학칙시행세칙 제22조의 1")는 참조 ID로 남긴다. 이것으로 조문 간 참조 그래프를 만든다.
4. 개정 이력, 시행일, 부칙 경과조치(어느 학번부터 적용되는지)를 메타데이터로 저장한다.
5. 수집일을 기록해 개정 여부를 추적한다.

```json

  "answer_type": "수치",
  "conditions": {"학번": 2025, "학사경고": true, "지원프로그램_이수": false},
  "gold_articles": ["학칙시행세칙#22의1", "학사경고자관리규정#6"],
```

## 5. 모델

### 5.1 전체 구조

```
질문      -> 한국어 인코더(고정) -> 입력 투영 -> 후각 감각 뉴런 2,639개 --+
후보 조문 -> 한국어 인코더(고정) -> 입력 투영 -> 시각 감각 뉴런 4,107개 --+
                                                                    |
                                                                    v
              수컷 CNS 전체: 뉴런 165,122개, 연결 2,454만 개
              (배선, 시냅스 수, 흥분/억제 부호는 고정. T스텝 동안 동역학 실행)
                                                                    |
                                                                    v
              하행 뉴런 1,314개 + 운동 뉴런 815개의 활동
                                                                    |
                                                                    v
   출력층: (1) 조문 관련성 점수 (2) 답 위치 포인터 (3) 판단 유형
                                                                    |
                                                                    v
              템플릿 답변 + 근거 조문 인용
```

입력은 머리 감각 뉴런에 넣고 출력은 하행 뉴런과 운동 뉴런에서 읽는다. 수컷 CNS는 뇌와 신경삭이 목으로 이어진 채 재구성됐기 때문에, 이렇게 하면 감각에서 운동까지 신경계 전체 경로를 쓰게 된다.

### 5.2 구성 요소

1. **한국어 인코더(고정)**: `klue/roberta-base`. 질문과 후보 조문을 벡터로 바꾼다. 어려운 문장을 읽는 능력은 대부분 여기서 나온다는 점을 전제로 하고, 커넥톰의 기여는 6장의 대조군으로 따로 잰다.
2. **입력 투영(학습)**: 질문 벡터는 후각 감각 뉴런으로, 조문 벡터는 시각 감각 뉴런으로 투영한다. 입력은 냄새를 맡는 시간처럼 T스텝 동안 일정하게 준다. 기본값은 T=16이다.
3. **전체 CNS 동역학(구조 고정)**: 뉴런 i의 상태 h_i를 다음과 같이 갱신한다.
   ```
   h_i(t+1) = (1 - 1/τ_k) * h_i(t) + (1/τ_k) * φ( g * Σ_j W_ij h_j(t) + 입력_i + b_k )
   W_ij = (뉴런 j의 부호) × (j에서 i로 가는 시냅스 수) / (행렬 W의 spectral radius)
   ```
   k는 뉴런 i의 세포 유형이고, τ_k(시간상수)와 b_k(휴지 상태)는 유형별로 공유한다. g는 전체 이득이다. φ는 tanh를 기본으로 하고 ReLU 계열과 비교한다. 부호를 붙인 원래 행렬의 spectral radius는 3,777.6으로 측정됐다.
4. **출력(학습)**: 하행 뉴런과 운동 뉴런 2,129개의 마지막 4스텝 평균 활동을 읽는다.
   - 관련성 헤드: 후보 조문이 정답 조문일 점수
   - 포인터 헤드: 벡터 두 개를 내보내 조문 토큰 벡터와 내적한 뒤, 답의 시작과 끝 위치를 고른다
   - 판단 헤드: 수치·기간 / 예·아니오 / 절차 / 조건 분기 / 답변 불가
5. **답변 조립**: 판단 유형별 템플릿에 뽑은 답과 근거 조문을 채운다. L4 질문은 관련성 점수가 기준을 넘는 두 번째 조문의 답을 "다만" 문장으로 덧붙인다.

### 5.3 고정하는 것과 학습하는 것

flyvis(Lappalainen 등, Nature 2024)의 방식을 따른다. flyvis는 연결 구조, 시냅스 수, 부호를 고정하고 세포 유형별 값 734개만 학습했다(유형 65개의 휴지전위와 시간상수, 유형 쌍 604개의 시냅스 강도 배율).

| 구분 | 항목 | 개수 |
|---|---|---|
| 고정 | 연결 구조, 시냅스 수, 흥분/억제 부호 | 연결 2,454만 개 |
| 고정 | 한국어 인코더 | 약 1.1억 파라미터 |
| 학습 | 입력 투영 (768차원 → 감각 뉴런 6,746개) | 약 518만 |
| 학습 | 세포 유형별 시간상수와 휴지 상태 | 약 2.9만 (유형 11,751개 × 2 + 유형 미지정 뉴런 2,605개 × 2) |
| 학습 | 출력 헤드 (2,129개 뉴런 → 관련성 1, 포인터 768×2, 판단 5) | 약 330만 |
| 확장 후보 | 유형 쌍별 시냅스 강도 배율 | 385만 (데이터가 적어 기본 설정에서는 제외) |

### 5.4 흥분과 억제 부호

| 신경전달물질 | 추적 뉴런 수 | 기본 부호 | 근거와 비고 |
|---|---|---|---|
| 아세틸콜린 | 103,718 | + | 초파리 중추신경계의 주된 흥분성 전달물질 |
| GABA | 22,055 | − | 억제성 |
| 글루탐산 | 29,296 | − | 초파리에서는 억제성 수용체(GluCl)를 통해 작용하는 경우가 많다. + 로 둔 버전을 실험 변수로 비교 |
| 히스타민 | 5,910 | − | 광수용체의 전달물질. 억제성 염소 통로를 연다 |
| 도파민, 옥토파민, 세로토닌 | 541 | 0 | 시냅스 밖에서 조절하는 물질이라 기본 설정에서는 연결에서 뺀다 |
| 불명 / 예측 없음 | 3,602 | 0 | 제외 |

### 5.5 단계별 발전 계획

| 단계 | 내용 | 목표 시점 |
|---|---|---|
| Stage 0 | BM25 키워드 검색. 형태소 분석기로 토큰화 | 6주 |
| Stage 1 | 커넥톰 저장소. 가중치와 유형별 값을 고정하고 출력 헤드만 학습 | 8주 중간발표 |
| Stage 2 | 유형별 시간상수와 휴지 상태, 입력 투영, 출력 헤드를 역전파로 함께 학습 | 11주 |
| Stage 3 | 참조 그래프 확장. 후보 조문이 가리키는 조문을 후보에 자동으로 추가해 L4 질문 대응 | 12주 |

후보 조문은 BM25로 상위 5개를 뽑고, 커넥톰 모델이 순위를 다시 매긴 뒤 답을 추출한다.

### 5.6 답변 예시 (L4)

> 질문: 25학번인데 학사경고 받고 지원 프로그램 안 들으면 다음 학기에 몇 학점까지 들을 수 있어?
>
> 답변: 2025학번 이후 입학생이 학사경고를 받고 지원 프로그램에 참여하지 않으면 다음 학기 최대 16학점까지 신청할 수 있습니다. 다만 지원 프로그램을 하나 이상 이수했거나 6학기 이상 이수했다면 제한이 없습니다.
>
> 근거: 학칙시행세칙 제22조의1, 학사경고자 관리 및 지원에 관한 규정 제6조

## 6. 실험 설계

### 6.1 비교 모델

| 구분 | 모델 | 확인하는 것 |
|---|---|---|
| Baseline | BM25 키워드 검색 | 원래 구상한 키워드 챗봇의 성능 |
| Baseline | 같은 인코더 + GRU (학습 파라미터 수를 커넥톰 모델과 맞춤) | 커넥톰 없이 같은 조건에서 어디까지 되는가 |
| Baseline | 같은 인코더 + 2층 MLP | 순환 구조 자체가 필요한가 |
| 상한선 | 인코더 fine-tune | 커넥톰 모델과의 격차 |
| 참고 | 티노랑 | 시험 질문 100개를 직접 물어 같은 기준으로 채점. 물어본 날짜를 기록한다 |

### 6.2 대조군

| 대조군 | 만드는 법 | 확인하는 것 |
|---|---|---|
| 무작위 망 | 같은 뉴런 수와 같은 연결 밀도의 무작위 희소 행렬 | 커넥톰이 아무 희소망보다 나은가 |
| 배선 섞기 | 뉴런마다 들어오고 나가는 연결 수는 유지하고 연결 상대만 무작위로 바꿈 | 정확한 배선의 효과와 연결 수 분포의 효과를 분리 |
| 가중치 섞기 | 배선은 유지하고 시냅스 수만 섞음 | 시냅스 강도 분포의 효과 |
| 부호 변경 | 글루탐산을 + 로 둔 버전 | 부호 규칙의 영향 |

2026년 9월에 나온 선충 커넥톰 저장소 연구는 커넥톰의 이점이 정확한 배선이 아니라 가중치 규모와 spectral radius에서 올 수 있다고 보고했다. 배선 섞기 대조군이 없으면 "초파리라서 좋았다"고 말할 수 없다.

### 6.3 절제 실험

전체 커넥톰이 있어야만 할 수 있는 실험이고, 이 프로젝트의 차별점이다.

| 제거 부위 | 뉴런 수 | 기대하는 관찰 |
|---|---|---|
| 시각엽 내재 뉴런 | 89,390 | 조문(시각 입력) 처리에 얼마나 쓰이는가 |
| 버섯체 케니언 세포 | 4,064 | 질문과 조문의 연합(기억) 기능이 필요한가 |
| 중심복합체 | 2,950 | 조건 조합이나 판단에 관여하는가 |
| 신경삭(VNC) | 약 20,350 | 출력을 운동 뉴런에서 읽는 의미가 있는가 |
| 목 절단 | 하행 1,314 + 상행 1,846 | 뇌와 몸의 연결이 끊기면 어떻게 되는가 |

감각 뉴런에서 다른 뉴런까지의 연결 단계를 세어 보니, 모든 뉴런이 머리 감각 뉴런에서 4단계 안에 닿았고 운동 뉴런은 대부분 2단계였다. 신호가 뇌 중심부를 거치지 않고 지름길로 갈 수 있다는 뜻이다. 절제 실험으로 실제로 쓰이는 경로를 확인한다.

### 6.4 데이터 양과 설계 변수

- 학습 질문 수를 100, 250, 500, 1,000, 전체로 바꿔 가며 학습 정확도와 검증 정확도의 차이(과적합)를 본다.
- 입력 위치: 질문은 후각, 조문은 시각(기본) / 둘 다 후각 / 감각 뉴런 전체
- 출력 위치: 하행+운동 뉴런(기본) / 버섯체 출력 뉴런 97개 / 뉴런 전체에서 무작위 2,129개
- 스텝 수 T: 8, 16, 32

### 6.5 지표와 통계

| 대상 | 지표 |
|---|---|
| 근거 조문 찾기 | Recall@1, Recall@5, MRR |
| 답 추출 | 수치·기간형 정확 일치(EM), span F1 |
| 판단 | 예·아니오 정확도, 답변 불가 판정의 정밀도와 재현율 |
| 전체 | 난이도(L1~L5)별 정답률 |

- 모든 모델을 서로 다른 시드로 5번 학습해 평균과 표준편차를 보고한다.
- 모델 간 차이는 질문 단위 쌍체 부트스트랩으로 검정한다.

### 6.6 오류 분석 범주

표 해석 오류, 교차참조 누락, 학번 조건 오적용, 구어체와 동의어 미인식, 부정과 예외 오판, 범위 밖 질문에 답해 버림.

## 7. 실행 환경과 비용

개발용 Mac(15코어 CPU, 24GB 메모리)에서 잰 값이다.

| 항목 | 측정값 |
|---|---|
| 가중치 파일 불러오기 최대 메모리 | 5.6GB (Colab 무료 약 12.7GB 안에 들어감) |
| 희소 행렬 곱 1스텝 (배치 32) | 0.152초 |
| 저장소 1스텝 (배치 100, tanh 포함) | 1.711초 |
| 16스텝 순전파+역전파 (배치 32) | 23.6초 |

- Stage 1: 질문 1,000개 × 후보 5개 = 5,000쌍. 16스텝 순전파만 하면 CPU로 약 23분이다.
- Stage 2: 같은 5,000쌍을 한 번 학습하는 데 CPU로 약 1시간이다. Colab 무료 CPU는 2코어라 CPU로는 부족하고 T4 GPU가 필요하다.
- **T4 GPU 속도는 아직 재지 않았다.** 6주차까지 측정해 Stage 2 계획을 확정한다.

## 10. 위험과 대응

| 위험 | 대응 |
|---|---|
| 커넥톰 모델이 같은 크기 GRU보다 못함 | 연구 질문을 "어느 난이도에서 도움이 되는가"로 잡아 두었으므로, 대조군과 절제 결과로 이유를 분석해 발표한다 |
| 성능 대부분이 인코더에서 나옴 | 같은 인코더를 쓴 GRU, MLP 대조군으로 커넥톰의 기여만 분리해 보고한다 |
| T4에서 Stage 2 학습이 너무 느림 | 스텝 수 축소, 후보 수 축소, 그래도 느리면 Stage 1과 유형별 값 일부만 학습하는 형태로 축소 |
| 순환 동역학 발산 | spectral radius 정규화, 시간상수 하한 설정, 기울기 자르기 |
| 평가셋 구축 부담 | 5주차부터 매주 할당량을 정하고, 시험셋은 팀원이 아닌 학생에게 질문을 받는다 |
| 규정 개정으로 정답이 바뀜 | 수집일을 고정해 평가하고, 데모 전에 다시 수집해 바뀐 조문을 표시한다 |
| 잘못된 안내 | 모든 답에 근거 조문을 붙이고, "최종 확인은 학사운영팀"이라는 안내를 넣는다 |

## 11. 먼저 확인할 것

1. 교수님께 이 구성(공개 규정 데이터, 직접 만든 평가셋, 공개 커넥톰)이 과목 요건에 맞는지 면담 시간에 확인한다.
2. 티노랑에 L3~L5 질문 20개를 물어 본다. 대부분 정확하면 차별점을 다시 잡아야 하고, 틀리거나 뭉뚱그려 답하는 사례는 문제 정의 자료로 쓴다.
3. T4 GPU에서 16스텝 순전파+역전파 속도를 잰다.
4. 별표·별지(HWP)를 범위에 넣을지 정한다. 넣는다면 PDF 보기 파일로 변환한다.
