# 산업기술경영대학원 학위수여규정

- 규정 번호(SEQ): 149, 이력 번호: 1767
- 분류: 제3편 행정 > 제4장 학사행정 > 대학원
- 담당 부서: 대학원, 대학원교학팀
- 제정·개정: 개정 2025.11.18. ...  (총 1건)
- 원문: https://rule.tukorea.ac.kr/lmxsrv/law/lawFullView.do?SEQ=149
- 수집일: 2026-09-27

<a id="a1"></a>
#### 제1조 (목적)

이 규정은 [대학원통합학칙](35_대학원통합학칙.md) 제3장에 의거 산업기술·경영대학원(이하 "대학원" 이라 한다) 학위수여에 관한 사항을 규정함을 목적으로 한다.  

<a id="a2"></a>
#### 제2조 (학위수여 요건)

다음의 요건을 갖춘 자에게는 학위를 수여할 수 있다.  
① 논문제출자  
  1. 전공학점 25학점 이상을 취득하고, 논문지도를 이수한 자  
  2. 평점평균이 3.0이상인 자  
  3. 학위청구논문 심사에 합격한 자  
② 논문대체학점 신청자  
  1. 전공학점 32학점(현장연구포함) 이상을 취득한 자, 단 고숙련마이스터 과정은 + PBL(OJT) 4학점 추가이수  
  2. 평점평균이 3.0이상인 자  
  3. 논문대체학점을 취득한 자  
③ 논문대체프로젝트 석사 학위 신청자  
  1. 전공학점 25학점 이상을 취득하고, 프로젝트 학위 심의를 신청하여 승인 받은 자  
  2. 평점평균이 3.0이상인 자  
  3. 논문대체 프로젝트 석사 학위 심사에 합격한 자<제정 2025.11.18.>  

<a id="a3"></a>
#### 제3조 (학위종별)

본 대학원에 수여하는 학위의 종별은 다음과 같다.  

| 학 과 (전 공) | 학 위 구 분 |
|---|---|
| 기술보호경영학과 | 경영학석사(기술보호경영학) |
| 기계공학과 | 공학석사(기계공학) |
| 기계설계공학과 | 공학석사(기계설계공학) |
| 메카트로닉스공학과 | 공학석사(메카트로닉스공학) |
| 전자공학과 | 공학석사(전자공학) |
| 컴퓨터공학과 | 공학석사(컴퓨터공학) |
| 신소재공학과 | 공학석사(신소재공학) |
| 생명화학공학과 | 공학석사(생명화학공학) |
| 나노반도체공학과 | 공학석사(나노반도체공학) |
| 디자인공학과 | 공학석사(디자인공학) |
| 전기공학과 | 공학석사(전기공학) |
| 스마트팩토리융합학과 | 공학석사(스마트팩토리융합공학) |
| 기계제조공학과 | 공학석사(기계제조공학) |
| 소프트웨어융합공학과 | 공학석사(소프트웨어융합공학) |
| 복지행정학과 | 정책학석사(복지행정학) |
| 스마트시스템융합학과 | 공학석사(스마트시스템융합공학) |
| AI탄소중립융합공학과 | 공학석사(AI탄소중립융합공학) |

<a id="a4"></a>
#### 제4조 (학위수여대상자 결정)

논문 심사위원회에서 통과된 학위논문은 대학원위원회에서 학위수여 여부를 결정하고 대학원장은 그 결과를 총장에게 보고하여야 한다.  

<a id="a5"></a>
#### 제5조 (학위수여시기)

본 대학원의 학위수여는 년2회로 하며 매년 2월과 8월중에 행한다.  

<a id="a6"></a>
#### 제6조 (학위수여)

본 대학원의 학위수여는 대학원장의 추천에 의하여 총장이 수여한다.  

<a id="a7"></a>
#### 제7조 (학위수여취소)

본 대학원의 학위를 받은 자로서 그 명예를 손상하는 행위가 있을 때에는 대학원위원회의 의결을 거쳐 그 수여를 취소할 수 있다.
